## Descripción

La Hormiga es una tienda en línea de venta general de productos, desarrollada como proyecto individual para el ETS de Ingeniería Web. Está hecha con **PHP 8, JavaScript, CSS, MySQL**, y la interfaz usa **Bootstrap 5** (cargado desde CDN).

El sistema maneja tres perfiles de usuario:

- **Cliente:** se registra, consulta el catálogo, agrega productos al carrito, guarda
  direcciones y métodos de pago, hace pedidos y revisa su historial.
- **Personal de inventarios:** administra productos, existencias e imágenes, y consulta
  las ventas.
- **Administrador:** administra usuarios, categorías, estatus, países, tipos de tarjeta y
  reseñas, y consulta reportes.

La base de datos está normalizada (3FN), con llaves foráneas e índices. El sitio está
publicado en HostGator.
